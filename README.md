# Destiny Achi Portfolio

A personal portfolio website for Destiny Achi, built as a clean, responsive single-page experience to showcase skills, selected projects, and contact information.

## Overview

This portfolio presents Destiny as a software engineering student with a focus on frontend development, problem-solving, and learning by building. The site includes a strong editorial visual style, a custom hero section, interactive mini-projects, and a contact form with validation.

## Features

- Responsive portfolio layout for desktop and mobile
- Custom hero section with branded identity and playful illustrations
- Animated ticker and section-based storytelling for portfolio content
- Featured project cards highlighting portfolio work
- Interactive palindrome checker
- Task manager with add, complete, and delete functionality
- Contact form with validation and toast notifications
- Dynamic footer year

## Run locally

Because this is a static website, you can run it in a few easy ways:

1. Open `index.html` directly in your browser.
2. Or use a local preview extension such as Live Server in VS Code.

Example:

```bash
cd my_portfolio
```

Then open `index.html` or start a local static server from your editor.

## Main sections

- Hero / introduction

## Interactive functionality

The JavaScript file implements:

- Mobile navigation toggle
- Palindrome validation logic

- Required field checks for the contact form
- Email and phone validation
- Toast feedback for user actions
